#  React Movie Search App

A modern and responsive **Movie Search Application** built with **React.js** that allows users to search for movies using the **OMDb API**. Users can instantly find movie posters, release years, and other basic information through a clean and user-friendly interface.

---

##  Features

-  Search movies by title
-  Display movie posters
-  View release year
-  Show movie details
-  Fast search experience
-  Fully Responsive Design
-  Clean and Modern UI
-  Dynamic API Integration

---

##  Built With

- React.js
- JavaScript (ES6+)
- HTML5
- CSS3
- OMDb API

##  Getting Started

### Clone the Repository

```bash
git clone https://github.com/yourusername/React-mini-project-movie-search.git
```

### Navigate to the Project

```bash
cd React-mini-project-movie-search
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm start
```

The application will run at:

```
http://localhost:3000
```

---

##  OMDb API Setup

1. Visit **https://www.omdbapi.com/**
2. Get your free API Key.
3. Add your API key to the project configuration.

Example:

```javascript
const API_KEY = "YOUR_API_KEY";
```
